# PeSNO: A Physics-Embedded Stream Neural Operator

**PeSNO** is a deep learning framework designed to accelerate high-fidelity numerical solvers for **incompressible flows with hard boundary constraints**. 

Instead of replacing the numerical solver entirely, PeSNO acts as a physics-consistent **warm-start mechanism**. It generates strictly **divergence-free initial guesses** using a hybrid spectral architecture (Discrete Sine Transform + Anti-symmetric Padding) and a physics-constrained weighted Sobolev loss.

## 💾 Data Preparation (Crucial)

This project relies on a high-fidelity benchmark dataset generated by a Teacher model (NewFluidNet). Due to size constraints, the seed data must be downloaded externally.

**Step 1: Prepare the `teacher` directory**
Ensure the `teacher/` folder exists in the root directory.

**Step 2: Download Resources**
Download the following files from [Zenodo Record: 15088589](https://zenodo.org/records/15088589):

1. **`TPH.zip`**: The raw simulation seed data.
2. **`trained_networks.zip`**: Extract `81_fluidnet_uvp.pt` from this archive.

**Step 3: Organize Files**
Unzip `TPH.zip` into `teacher/` and place the weight file there. The structure must look exactly like this:

```text
PeSNO-Master/
└── teacher/
    ├── 81_fluidnet_uvp.pt          <-- Weights file
    ├── pytorch_networks_convae.py  <-- Existing script
    └── TPH/                        <-- Unzipped folder
        └── sims.pt                 <-- Key config file
```

## 🚀 Usage Workflow

### 1. Data Generation (Physics-Augmented Pipeline)

We employ a hybrid pipeline to generate physics-consistent training data, ensuring mass conservation and temporal continuity.

* **Step A: Generate Primitive Variables**
This script runs the RK4 solver with divergence-free projection to generate velocity and temperature fields.
```bash
python generate_data.py
```


* **Step B: Generate Stream Functions**
This post-processing step solves the Poisson equation $\nabla^2 \psi = -\omega$ to generate ground truth stream functions used for PeSNO training.
```bash
python generate_psi.py
```



### 2. Model Training

We provide isolated training scripts for PeSNO and two baselines to ensure a fair comparison.

* **Train PeSNO (Proposed Method)**
```bash
python train_pesno.py
```
*Key Features: Discrete Sine Transform (DST), Anti-symmetric Padding, Hard Boundary Mask, Sobolev Loss.*

* **Train Baselines**
```bash
python train_baseline_fno.py      # Fourier Neural Operator (Periodic assumption)
python train_baseline_resunet.py  # Res U-Net (Pixel-wise CNN)
```



## 📊 Evaluation & Visualization

* **Logs**: Training metrics (L2 Reconstruction Loss, H1/H2 Sobolev Norms) are saved to `training_log_*.txt`.
* **Visuals**: Field reconstructions (Stream Function, Velocity, Vorticity) are saved to `visuals_*/` every epoch to monitor physical fidelity.
